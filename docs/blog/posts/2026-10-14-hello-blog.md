# 新博客建立啦

折腾了一阵，博客终于上线了。第一篇先说说为什么要写，以及这个站是怎么搭的。

<!-- more -->

## 为什么要写博客

理由大概是这三个：

1. **写下来才算真的懂。** 一个题想通了、一个 trick 记住了，如果不写下来，
   过两周就只剩「我好像见过」这一层印象。
2. **给自己留档。** 散落在本地文件夹里的 `.md`、`.cpp`、对拍脚本，
   迟早会在换电脑的时候丢掉。
3. **也许有人看。** 如果某篇推导能让另一个人少卡两小时，那也挺好。

## 这个站是怎么搭的

技术选型上抄了几位朋友的作业：

- **MkDocs Material**：Markdown 写作，侧栏树形导航适合放算法笔记；
  搜索、深色模式、代码复制按钮都是内置的。
- **KaTeX**：数学公式，配 `pymdownx.arithmatex` 使用。
- **GitHub Pages + GitHub Actions**：`git push` 之后自动构建部署。
- **RSS**：`/feed_rss_created.xml`，可以直接丢进阅读器。

写作流程就是：

```powershell
.\scripts\serve.ps1   # 本地预览 http://127.0.0.1:8000
git add -A
git commit -m "post: 新博客建立啦"
git push              # 30 秒后线上更新
```
