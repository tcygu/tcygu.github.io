# 算法笔记

按知识点整理的笔记。左边目录里每个大类点进去是该类的目录页。

| 分类 | 说明 |
| --- | --- |
| [动态规划](dp/index.md) | 线性 DP、区间 DP、状压、数位、DP 优化 |
| [数据结构](ds/index.md) | 线段树、BIT、平衡树、树剖、分治 |
| [数学](math/index.md) | 数论、组合、生成函数、多项式、线性代数 |
| [图论](graph/index.md) | 最短路、网络流、连通性、图论定理 |
| [字符串](string/index.md) | KMP、AC 自动机、后缀数组/自动机 |
| [杂项](misc/index.md) | 取模优化、二分、离线技巧 |

!!! tip "写作模板"

    新建一篇笔记，只要在对应目录下加一个 `.md` 文件，然后在 `mkdocs.yml`
    的 `nav` 里加一行即可：

    ```markdown
    # 高维前缀和（SOS DP）

    ## 问题

    ...
    ```
